Problem and impact

Scam messages reach people before help does.

Digital scams increasingly arrive through everyday messaging apps. A fake bank alert, delivery notice, job offer, or urgent family request can pressure someone to click, share private information, or send money before they can verify the message.

Immediate

AEGIS responds inside WhatsApp, where suspicious messages already arrive.

Accessible

Users receive plain-language explanations instead of technical security jargon.

Protective

The system gives concrete next steps before a user clicks or shares sensitive data.

Who this helps

  • Students and families receiving suspicious links or financial messages.
  • Older adults and less technical users who need clear, fast guidance.
  • Anyone who wants a second opinion before acting on a risky message.

Core insight

The safest security tool is the one people can use in the exact moment of risk.

Solution

A WhatsApp AI agent that turns suspicious content into safety guidance.

A user forwards suspicious content to AEGIS. The platform verifies the webhook, processes the report asynchronously, uses Gemini through a Google ADK agent workflow, stores privacy-safe case state, and sends a plain-language risk explanation back to WhatsApp.

1

Forward suspicious content

Text, links, images, and voice notes can be sent directly to the bot.

2

Agent investigates

The ADK agent analyzes manipulation patterns, phishing indicators, and known scam signals.

3

Receive plain-language help

The user gets a verdict, explanation, and next steps in the same WhatsApp thread.

Agent workflow

analyze_content check_sender_reputation cross_reference_reports draft_protective_action escalate_or_close

This moves AEGIS beyond a basic chatbot. It receives a goal, processes events, uses tools, persists memory, and can continue case handling through asynchronous follow-up.

Architecture

Production-style cloud architecture, built for real message flow.

AEGIS is separated into small services with clear security boundaries. Ingestion does not call the model directly. Agent processing is decoupled through Pub/Sub. User contact data is protected with hashing, Cloud KMS, and Secret Manager.

Privacy and reliability

  • Meta webhook signature verification before processing.
  • HMAC-hashed user IDs for stored records and logs.
  • Encrypted contact directory for WhatsApp replies.
  • Pub/Sub retry and dead-letter design for failures.
  • Fallback reply when model quota is temporarily exhausted.
